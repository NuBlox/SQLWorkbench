# NuBlox SQL Workbench 0.2.0-rc.1

This is the first cross-platform release candidate for NuBlox SQL Workbench.

## Included

- Electron + Svelte desktop application with secure custom renderer protocol and typed preload boundary.
- Published `@nublox/mysql@3.1.0-rc.1` integration for MySQL connectivity.
- Published `@nublox/metaobject@1.0.0-rc.1` integration for logical metadata/schema engineering.
- Persistent connection profiles with OS-backed credential encryption.
- Monaco SQL editor, statement/selection/script execution, cancellation, history and result export.
- Database explorer covering schemas, tables, views, columns, indexes, foreign keys, routines, triggers, events, users, roles and privileges.
- Schema, view and ER engineering with guarded DDL execution.
- Query intelligence, formatting, semantic diagnostics, visual query builder, explain-plan visualization and plan/statistics history.
- Administration and operations:
  - sessions/processes;
  - locks/blocking;
  - server variables and status;
  - users, roles and privilege inspection plus guarded grant/revoke/role changes;
  - storage/capacity inspection;
  - bounded JSON/CSV export and JSON import;
  - bounded data compare and guarded append transfer;
  - MySQL logical backup/restore hooks using `mysqldump` and `mysql`.

## Safety boundaries

- Database passwords and TLS private keys remain outside connection-profile persistence.
- Security changes are previewed as exact provider SQL and require a matching preview fingerprint plus an explicit confirmation phrase.
- Schema/view/ER changes retain stale-preview fingerprint protection.
- Import/export and transfer operations are capped at 10,000 rows per operation in this RC.
- Restore requires the exact confirmation phrase `RESTORE DATABASE`.
- Backup/restore passwords are passed only in the spawned process environment; they are not placed in command-line arguments.

## Packaging status

The GitHub release workflow builds native macOS, Windows and Linux packages. RC artifacts are intended for testing and may be unsigned. Production distribution still requires platform code signing; macOS production distribution also requires notarization.

MySQL backup/restore requires the relevant MySQL command-line tools (`mysqldump` and `mysql`) to be installed and available on `PATH`.

## Testing focus

Please exercise:

- connection creation, secure credential persistence and reconnect;
- SQL execution/cancellation/export;
- schema/view/ER preview and guarded execution;
- query completion/diagnostics/formatting/explain plans;
- Administration tabs against both privileged and restricted MySQL accounts;
- data import/export and compare/transfer against disposable test data;
- backup and restore against a disposable database.

Report release-candidate defects in the SQLWorkbench GitHub repository with operating system, MySQL version, reproduction steps and any visible Workbench error text/startup log.
