# NuBlox SQL Workbench 0.1.0-rc.2

Second release candidate for the first MySQL-focused NuBlox SQL Workbench desktop product path.

## Why rc.2 exists

`v0.1.0-rc.1` validated the application and produced the macOS artifact, but the tag-triggered release workflow exposed two platform-packaging defects before a GitHub prerelease could be published:

- Linux inherited the scoped npm package name as its executable name, which is not a valid AppImage executable path;
- Windows invoked `electron-builder` through a temporary `pnpm dlx` installation whose NSIS template include path was incomplete.

The rc.1 tag is retained as an immutable record of that attempted release. rc.2 fixes the packaging path rather than moving or rewriting rc.1.

## Packaging corrections

- pin `electron-builder` 26.15.3 as a desktop development dependency;
- invoke the repository-local `electron-builder` binary instead of `pnpm dlx`;
- set the cross-platform executable name explicitly to `NuBlox-SQL-Workbench`;
- ignore generated `release/` directories;
- require release-branch pull requests to build the real macOS ZIP, Linux AppImage and Windows portable executable before merge.

## Product scope

Product functionality is unchanged from rc.1. The MySQL-focused M0-M6 path remains the candidate product scope, including SQL authoring/execution, database exploration, Metaobject integration, schema/query engineering, guarded administration, import/export, comparison/transfer and backup hooks.

## Artifact targets

The release workflow publishes:

- macOS ZIP;
- Linux AppImage;
- Windows portable executable.

RC artifacts remain unsigned and unnotarized. Signing, notarization, branded application icons and installer polish remain post-RC hardening work.

## Validation gate

rc.2 is not promoted until all of the following pass from the release branch:

1. full monorepo `pnpm check`;
2. generic Electron package assembly;
3. macOS ZIP packaging;
4. Linux AppImage packaging;
5. Windows portable packaging.

After merge, tag `v0.1.0-rc.2` triggers the same cross-platform packaging matrix and GitHub prerelease publication.
